У цьому модулі стилі розділяються на окремі файли за призначенням — замість
одного великого файлу стилів.

Створи папку css і додай до неї файли:

main.css — головний файл, який підключається в HTML; common.css — загальні стилі
сторінки; header.css — стилі шапки; hero.css — стилі Hero-секції; features.css —
стилі секції Features; team.css — стилі секції Team; portfolio.css — стилі
секції Portfolio; footer.css — стилі підвалу.

Далі:

Підключи до HTML лише файл main.css. У main.css за допомогою директиви @import
підключи решту CSS-файлів. Переконайся, що стилі застосовуються до сторінки.
